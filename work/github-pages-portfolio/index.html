GitHub Pages Portfolio

Operating the public GitHub Pages site as a durable home for essays, notes, photography, and selective technical work.

2026 · Product strategy, design system, frontend implementation

Outcomes

  • Established a coherent public narrative across writing, photography, and technical work.
  • Created a file-based editorial workflow that lowers the friction to publish.
  • Replaced an outdated one-page résumé site with a real public site structure.

Stack

  • Static GitHub Pages
  • Content collections
  • Editorial design

The main challenge here was coherence.

A lot of personal sites become adjacent containers: one page for work, another for writing, another for photographs, with no deeper argument connecting them. This project takes the opposite approach. The shared idea comes first, and the information architecture follows from it.
